Windows Kurulum Simülatörü

Nasıl oynanır?

Windows 10/11 kurulumunda takip edilen adımların birebir çizimlerini ve açıklamalarını içeren bu eğitim oyununda her aşamayı doğru sırayla uygulamanız gerekir.

  • Ekranın solundaki zaman çizelgesi hangi adımda olduğunuzu gösterir.
  • Sağ alt köşede ilerleme ve puan bilgilerinizi görebilirsiniz.
  • Yanlış seçim yaptığınızda açıklayıcı geribildirimler sunulur.

İpucuna ihtiyacınız olursa İpucu düğmesine tıklayabilirsiniz. Tüm adımlar tamamlandığında özet raporu görüntüleyebilirsiniz.
